⚽ Analizador de Fútbol

Busca partidos, compara probabilidades y detecta posibles diferencias entre pronóstico y cuota.

1. Conectar datos deportivos

Esta versión usa API-Football para consultar partidos, predicciones y cuotas disponibles. Necesitas una clave API propia. La cobertura y el límite diario dependen del plan contratado.

La clave se guarda solo en el almacenamiento local de este navegador. No la publiques ni la compartas. Para una aplicación pública de varios usuarios, la clave debe moverse a un servidor protegido.

Sin conectar. Añade tu clave y pulsa “Buscar partidos”.

2. Búsqueda automática

La búsqueda abarca las competiciones que la API tenga disponibles. Se consultan primero los partidos y después, dentro del límite elegido, sus predicciones y cuotas. Esto puede consumir varias solicitudes de tu cuota API.

4. Historial de análisis

El historial registra las oportunidades detectadas en este navegador. Esta versión todavía no obtiene automáticamente el resultado final para liquidar pronósticos.

Cómo interpretar los resultados

  • Probabilidad: estimación de la fuente de datos, no una certeza ni garantía de acierto.
  • Probabilidad implícita: 1 dividido entre la cuota decimal; no elimina por sí sola el margen de la casa.
  • Ventaja estimada: (probabilidad estimada × cuota) − 1. Es una señal preliminar, no prueba de valor real.
  • Filtro: solo muestra mercados que tienen probabilidad y cuota disponibles y cumplen los límites que elegiste.
  • Sin datos no hay pronóstico: no se inventan cuotas ni predicciones cuando la API no los entrega.
Importante: la versión 2.0 es un prototipo de investigación. Las predicciones de terceros pueden tener cobertura desigual; las cuotas pueden cambiar. No apuesta automáticamente ni promete ganancias. Evalúa muchos pronósticos y la calibración antes de confiar en el modelo.
